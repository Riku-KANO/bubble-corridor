# 要件 ID（受け入れ基準）

設計書（[spec.md](spec.md)、原本は Claude Docs）を、テストで確かめられる単位に分けて ID を振る。
テスト名・`describe` に ID を含める（例: `describe('RIDE-2 動きの上限', …)`）。数値は [src/config.ts](../src/config.ts)。
「人」と書いた項目は機械で測れないので、関門（[gates.md](gates.md)）で人が確かめる。

## RIDE 乗り物と時間（src/ride）

- **RIDE-1 区間と時刻**: 乗車は 780 秒（234 小節、72BPM）。7区間の開始は 0:00 / 1:00 / 3:30 / 6:00 / 8:00 / 11:00 / 12:30。`sectionAt` と `sectionTime` がこの表どおり。
- **RIDE-2 動きの上限**: 標準モードで、前進 ≤3.0 m/s、加減速 ≤0.5 m/s²、上下 ≤0.6 m/s、向きの回転 ≤15°/s、常に水平。速度の変化は2秒以上かける。`analyzeComfort` が違反 0 件。
- **RIDE-3 速度の決め方**: 位置は時刻表（t → s）から決める。普段 1.0〜2.0 m/s。各見どころの時刻の前後（±2秒）は 0.5 m/s 前後（≤0.7）。部屋の入口（膜の直後）は減速している（直前より遅い）。
- **RIDE-4 穏やかモード**: 同じ時刻表（乗車時間 780 秒、同じ s(t)）で、上下 ≤0.3 m/s、向きの回転 ≤7.5°/s。
- **RIDE-5 キューシート**: 時刻は config の小節から計算する（見どころはすべて小節の頭）。名前・時刻・区間が設計書どおり（`buildCueSheet`）。誘導（lure）は見どころの3秒前。撮影は 2:40 / 5:10 / 9:50。
- **RIDE-6 出来事の配信**: 出来事は時刻順に一度だけ流れる。フレームが飛んでも取りこぼさない。ポーズ中は流れない。`reset(t)` の後は t より前を流さない。
- **RIDE-7 部屋の先読み**: 今の部屋にいる間に次の部屋を読み込み、2つ前の部屋は解放する。膜の前後（±数秒）は両方の部屋を描く。
- **RIDE-8 レールの形**: レールは連続（隣の点の間隔が spacing±10%）で、部屋ごとの広さ（温室: 大、回廊: 小、天球: 最大、岸: 開放）に合わせた区間を持つ。物との最短距離 0.5m は部屋の担当が守る（人）。

## AUD 音楽と音（src/audio、src/core/sound）

- **AUD-1 構成データ**: 7区間＋万華鏡の金・青の構成データ（JSON）が 72BPM・計 234 小節。区間ごとに調、和音の進行、主題、層（持続音・分散和音・旋律・リズム・きらめき）と強さの変化を持つ。リズムは万華鏡で初めて入る。
- **AUD-2 音階への揃え**: 触れた音は、その瞬間の和音と部屋の調の5音の共通部分から選ぶ（2音未満なら5音）。`pentatonic`・`chordTones`・`touchCandidates`・`nearestPitch`。
- **AUD-3 拍への合わせ**: 触れた音は次の8分音符の格子に鳴らす（`nextGridTime`、予約の余裕 minLead を守る）。
- **AUD-4 うるさくならない**: 同時に鳴る触れた音は8まで。同じ物は0.3秒以内に再び鳴らない（`touch` が null を返す）。
- **AUD-5 時計**: 楽曲の再生位置が時計。ポーズで止まり、同じ位置から続く。先の音まで予約して鳴らす（描画が重くても遅れない）。
- **AUD-6 立体音響と残響**: 音は 3D に置き HRTF で鳴らす。誘導音は見どころの方向から。残響は部屋の広さで変える（回廊は短く、天球は長く）。音量は全体・音楽・効果音・環境音を別々に。
- **AUD-7 膜と見どころの音**: 膜を通る瞬間に次の区間の曲へ切り替え、膜ごとに音程の違う通過音を鳴らす。雨が止まった瞬間にほぼ無音にする。

## INT 触れる（src/input、src/xr、部屋）

- **INT-1 必ず応える**: 触れられる物は近づくと縁がかすかに光る。触れると 0.1 秒以内に光と動きで応える（`onTouch` が同じフレームで呼ばれる）。
- **INT-2 見つめて触れる**: 同じ物を設定の秒数（0.8 / 1.2 / 2.0）見つめると触れる。視線が外れたら数え直す。全環境で有効。
- **INT-3 見どころは邪魔させない**: 見どころの演出中も触れられ、演出は止めない（部屋の担当、人）。
- **INT-4 何もしない人にも**: 触れられないままの物は、ゴンドラが近づくと一度だけ自分で小さく鳴る。
- **INT-5 見逃させない**: 見どころの3秒前に誘導（方向からの音と光の粒）。PC とスマートフォンでは、正面から 45° 以上外れていればやさしく正面へ戻す（設定でオフ）。VR ではカメラを回さない。
- **INT-6 隠し要素**: 各部屋に小さな泡が1つ（全5つ）。触れると特別な和音。見つけた数はブラウザに残り、額縁が変わる。
- **INT-7 乗車の記録**: 触れた数、選んだ扉、描いた星座、見つけた泡。点数や順位はつけない。
- **INT-8 分岐**: 雨の回廊の終わりで琥珀・瑠璃の扉。触れた方・長く見つめた方へ。何もしなければ瑠璃。2周目は前回と違う扉が少し強く光る。

## CAM カメラ（src/input、src/app）

- **CAM-1 見回し**: 座席に固定。正面から左右 ±120°、上下 ±60° に収める。視野角 75°（60〜90）。ドラッグで回す / マウスの位置に追従を選べる。
- **CAM-2 傾き**: スマートフォンの傾きは許可制。断られたらドラッグ。
- **CAM-3 VR**: 頭の動きだけを反映し、演出でカメラを動かさない。座る / 立つ、正面の合わせ直し、移動中の外周の暗さ。

## UI 画面（src/ui）

- **UI-1 流れ**: 待ち列 → 入口 → 案内（初回だけ、6秒で自動、飛ばせる）→ 乗車 → ライドフォト。もう一度乗るは待ち列と案内を飛ばす。ポーズの「降りる」は入口へ。
- **UI-2 乗車中は何も出さない**: 固定の表示はゼロ。マウスを動かしたときだけ隅に雫が2秒。0:20 に一度だけ「触れると、鳴ります」。
- **UI-3 言語**: 日本語と英語。初期値はブラウザの言語。すべての文言は ja・en の両方のキーを持つ。
- **UI-4 設定**: 画質 / 見回し / 快適さ / 音 / 表示 のタブ。変更は即時反映し、保存する。壊れた保存は既定値に戻す。
- **UI-5 アクセシビリティ**: 見つめる時間 3段階、光の点滅を抑える、文字の大きさ 3段階、音なしでも光で分かる、正面へ戻すのオン/オフ、見回しの方式。
- **UI-6 文字**: 最小 18px（1080p 基準）、スマートフォン 16px 相当以上。生の HTML を挿入しない。

## PHO ライドフォト（src/photo）

- **PHO-1 撮影**: 2:40 / 5:10 / 9:50 に自動で撮る。画面の演出を止めず、別に高解像度（PC 2560×1440、スマートフォン 1920×1080）で描く。
- **PHO-2 合成**: 額縁（隠れた泡 0〜1: 通常、2〜3: 銀、4: 金、5: 虹色）、刻印（「泡沫回廊・第3便・2026.10.20」/ "Utakata · Ride No.3 · 2026.10.20"）、扉の色。横長 1920×1080 と正方形 1080×1080。
- **PHO-3 保存**: IndexedDB に最新10回分。11回目で最も古いものを消す。ダウンロードと、スマートフォンでは端末の共有機能。

## TRN 遷移（src/app、src/fx、部屋）

- **TRN-1 膜**: 部屋の境目はすべて膜。通過の 0.6 秒に虹色の縞と歪み。
- **TRN-2 黒い画面を使わない**: 例外は天球の 2 秒の暗転だけ。
- **TRN-3 遷移の長さ**: 設計書「遷移の一覧」の秒数（config の TRANSITION_SEC）。

## REN 描画と性能（src/app、src/core、src/fx）

- **REN-1 3つの描画経路**: WebGPU、WebGL2（`?webgl`）、VR（WebGL2 経路。M0 で確定）で同じ部品が動く。
- **REN-2 品質プリセット**: 端末の手がかりから自動で選ぶ（スマートフォン・VR は低め）。動的な解像度調整で目標 fps を保つ。
- **REN-3 性能の目標**: PC 1080p 60fps、スマートフォン 30fps、Quest 3 72fps（目標 90）、1部屋の GPU メモリ 300MB 以下。初回の読み込み 10MB 以下、各部屋 15MB 以下。

## CORE 共通部品（src/core）

- **CORE-1 境界**: src/core は core の外を import しない（`scripts/check-core.ts`）。
- **CORE-2 版**: 変更したら VERSION と CHANGELOG.md を更新する。案1へは `pnpm core:sync` でコピーする。
- **CORE-3 ガラスの材質**: 透明・曇り・色・虹色・乳白・鏡の6種。縁の光（setHighlight）と触れたときの波紋（pulse）。透過を使わずに縁の反射と薄膜干渉で見せる。3経路で同じ見た目（人）。
- **CORE-4 曇りと指の文字**: 曇らせる・晴らす・指でなぞる文字・消す。canvas に描き、DOM にも 3D にも使える。
